## 🎯 Image Download Tips

### Recommended Sources:
1. **Pexels** (https://www.pexels.com) - Free high-quality images
2. **Unsplash** (https://unsplash.com) - Free professional photos
3. **Pixabay** (https://pixabay.com) - Free stock images

### Search Keywords by Category:
- **Plumbing**: "bathroom fixtures", "plumbing work", "sink installation"
- **Electrical**: "electrician", "electrical work", "lighting installation"
- **Cleaning**: "cleaning service", "bathroom cleaning", "car wash"
- **Call A Service**: "delivery", "taxi", "photographer", "towing"
- **Finance**: "tax documents", "legal papers", "business registration"
- **Personal Care**: "salon", "medicine", "health checkup"
- **Civil Work**: "house painting", "tile work", "home renovation"

### Image Specifications:
- **Format**: JPG or PNG
- **Size**: 800x600px or higher
- **Aspect Ratio**: 4:3 or 16:9
- **File Size**: < 500KB (optimize before uploading)
- **Quality**: High resolution, professional-looking

### Optimization:
Use online tools to compress images:
- TinyPNG (https://tinypng.com)
- Squoosh (https://squoosh.app)
- ImageOptim (for Mac)

## 🔄 After Downloading Images

Once you've added images to the folders, update the database with:

```sql
UPDATE services 
SET image_paths = '{
  "/images/subcategories/{category}/{subcategory}/{image-1}.jpg",
  "/images/subcategories/{category}/{subcategory}/{image-2}.jpg"
}'
WHERE id = 'service-uuid-here';
```

Or use the bulk update script if needed.
